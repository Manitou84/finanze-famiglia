# Finanze di Famiglia — web app per iPhone

Si pubblica gratis con GitHub Pages; i dati restano su Supabase, protetti dal login.

## Pubblicare (la prima volta)

1. Su github.com apri il repository `finanze-famiglia`.
2. **Add file › Upload files**: trascina **tutti i file di questa cartella** (non la cartella stessa) e premi **Commit changes**.
3. **Settings › Pages**: Source «Deploy from a branch», Branch `main`, cartella `/ (root)`, **Save**.
4. Dopo 1–2 minuti l'app è su `https://TUO-UTENTE.github.io/finanze-famiglia/`.
5. Su Supabase: **Authentication › URL Configuration** → in **Site URL** metti quell'indirizzo e aggiungilo anche in **Redirect URLs**.
   Serve perché i link delle email (conferma account, nuova password) riportino all'app.

## Sull'iPhone

Apri l'indirizzo con **Safari** › Condividi › **Aggiungi alla schermata Home**, poi accedi.
Chi è stato invitato dal Mac sceglie **Primo accesso**.

## Aggiornare

Ricarica su GitHub i file cambiati: il telefono prende la nuova versione alla prima apertura con rete.
